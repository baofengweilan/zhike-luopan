# 0009 - 文件导入课表（Word/PDF/Excel/图片）+ 课表页周网格改版

日期：2026-10-02。用户提出：课表页要像完美校园一样支持导入文件建课表；AI 助手要能收文件/图片并"看懂办事"；界面改为周网格卡片式。经拷问敲定如下，与 ADR 0008（Agent 化）合并实施。

## 决策

### 1. 架构：一份解析管道，两个入口（用户选 A 合并）

```
解析管道：上传文件 → 类型分发 → 内容提取 → 混元结构化 → 确认卡片 → 入库
入口 A（AI 助手）：发文件给 AI → Agent 调 import_schedule_file 工具 → 确认卡片 → 执行
入口 B（课表页）：「导入课表」按钮 → 选文件 → 同一管道 → 确认卡片 → 执行
```

`import_schedule_file` 追加进 ADR 0008 第 4 条的工具清单（共 7 个工具）。演示主线可串联："发个文件给 AI → 它看懂了 → 请求授权 → 执行"。

### 2. 文件类型与实现路径（用户拍板：四种全支持，路径各异）

| 类型 | 提取 | 结构化 | 本期承诺 |
|---|---|---|---|
| Word | python-docx | 混元 hy3 | 必做保底 |
| Excel | openpyxl | 混元 hy3 | 必做保底 |
| PDF（文本型） | pdfplumber | 混元 hy3 | 必做 |
| 图片 / 扫描 PDF | 混元多模态视觉模型直读 | 同上（视觉模型直接出结构） | 必做，**带验证关卡** |

- 图片路径用混元视觉模型（不走 DeepSeek——其 flash 档纯文本会忽略图片）
- **验证关卡**：10-09 前实测视觉模型对课表截图的识别质量；不达标则切腾讯云 OCR 兜底（通用文字识别 1000 次/月免费，OCR 只出文字丢布局，后接混元理解结构，链路更长故为备选）

### 3. 周次规则近似映射（用户选 B）

真实课表含任意周次集合（"周5无课"、"12-13周,15周"），现模型只有每周/单/双周。导入映射规则：

- 全奇数周 → 单周；全偶数周 → 双周
- 其他 → 按每周处理，课程备注写明"实际为 12-13,15 周"
- 导入完成后 AI 汇报："有 N 门课的周次为特殊规则，已按近似处理并备注"

任意周次列表数据模型（`[12,13,15]`）列入赛后改进。

### 4. 界面改版（用户选 A：本期重做课表页）

- **课表页**：重做为周网格卡片式（完美校园风格，彩色课程卡片 + 周次切换），与导入入口**合并为同一次前端改造**
- **其他页面**：轻度美化（配色、卡片质感），不动结构；首页遵循 ADR 0006 课表即首页
- 配色布局：先按完美校园风格出原型给用户过目再调

### 5. UI 改版新增确认卡片的落点

确认卡片（ADR 0008）是新增交互组件，随本次前端改造一并实现。
