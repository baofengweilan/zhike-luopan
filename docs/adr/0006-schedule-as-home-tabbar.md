# 0006 - 课表即首页，三 tab 导航（课表 / AI 助手 / 我的）

首页原为"导航卡片菜单"，核心对象课表距首屏两次点击，评委 30 秒内建立不了产品认知。决策：`pages/schedule` 升格为启动页与第一个 tab，底部 tabBar 三项（课表 / AI 助手 / 我的），旧 `pages/index` 删除；学期管理、教材、相册、提醒降级为「我的」二级入口，时令/作息/校历/模板保持挂在学期管理之下（它们是学期子资源，天然带学期上下文）。备选"保留菜单首页仅把课表卡片数据化"被否——治标不治本；"全量视觉翻新"被否——双赛截止（2026-10-15/17）前失控。Consequence：tab 页不能用 `navigateTo` 携参跳转，跨页学期上下文改走 `globalData.pendingSemesterId`（semesters/ai → schedule）；无学期时首屏渲染引导卡而非灰按钮；tabBar 图标属后续视觉统一阶段（暂纯文字）。
