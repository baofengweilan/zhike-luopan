# 演示脚本（评委答辩用）

> 对应 AI Coding 赛五维度：AI 编码能力运用 / 创新性 / 技术实现 / 应用价值 / 展示与文档。
> 演示前运行 `python scripts/seed_demo.py` 刷新种子数据；录屏建议 5–8 分钟走完以下动线。

## 动线 1：一句话调课（AI 编码能力运用 + 创新性）⭐

1. 首页 → **AI 课表助手**
2. 输入：`把周一第3节大学英语改到第5节`
   - 预期：AI 返回"已把「大学英语」调到周一第5节，课表已重新生成（N 节）"
3. 点气泡里的 **"课表已更新，点这里查看"** → 周一列表看到变化
4. 再输入：`周三第1节加一门人工智能导论 单周` → 只在单周生成

**讲解点**：自然语言 → 结构化规则 → 应用到模板 → 实例全量重生成，冲突校验在应用层强制执行。MoMA 大模型解析 + 规则引擎兜底，接口一次定型。

## 动线 2：数据驱动问答（应用价值）

- `最近什么时候放假？` → 精确到国庆/校庆等真实校历
- `明天有什么课？` → 带时间、地点的完整回答

**讲解点**：答案全部来自用户真实课表数据，大模型模式下注入两周课表 JSON 上下文并约束"不要编造"。

## 动线 3：时令作息 + 单双周（技术实现）

1. 学期管理 → 时令管理 → 配置春/秋作息不同起床时间
2. 作息时间表 → 时间轴预览
3. 课表模板 → 加一门 `单周` 课程 → 课表页"重新生成" → 只有单周出现

**讲解点**：第 1 周锚定（start_date 所在自然周）、周次模式匹配、时令自动切换——"第 3 节到底几点"的痛点被规则引擎消化。

## 动线 4：假期与调休（应用价值）

1. 校历管理 → **AI 解析公告**：粘贴 `10月9日至10月10日放假，10月10日上班`
2. 课表页 → 放假日的课消失；补班日按周五课表出现
3. 点任意课程 → 调整 → 挪到假期 → **实时冲突提示** + 空闲时段建议 → 点建议直接应用

**讲解点**：2026 国家节假日静态种子（运行时零外部依赖）+ AI 公告解析；冲突检测分硬/软两级；调整全量快照留痕可回滚。

## 动线 5：扫码录教材（应用价值，演示效果好）

1. 我的教材 → 📷 扫码录书 → 扫教材背面条码
2. Open Library 命中 → 书名/作者/封面自动入库；演示环境外网不通时 → 手动录入 + 拍封面兜底
3. 绑定到课程 → 课表点开该课 → 详情里显示封面

## 动线 6：提醒与日历（展示与文档）

1. 提醒管理 → 生成未来 7 天课前提醒 + 假期提醒
2. 订阅消息：无微信密钥时走站内提醒（状态机一致），上线后一键切真实推送——额度耗尽自动降级，产品上明示
3. 课表页 → **📅 导出到日历** → 分享 .ics 给文件传输助手 → 手机导入系统日历

## 兜底说明（评委追问时）

- 扫码失败 → 手动录入 + 拍封面（不会死路）
- 微信推送需已备案域名 + 订阅模板 ID，演示环境站内提醒等价展示状态机
- 订阅消息一次性授权额度限制是微信平台约束，产品策略：打开即批量请求授权 + 额度耗尽降级
