# ai-proxy 云函数部署指南（面向零基础，全程网页操作，约 10 分钟）

这个云函数的作用：把腾讯"成长计划"送的 AI 额度（只允许云开发 SDK 调用）翻译成
咱们后端会说的 OpenAI 语言。部署完成后把它的访问地址告诉 ZCode 即可。

## 第 1 步：打开云开发控制台

1. 浏览器打开 https://tcb.cloud.tencent.com/ 并登录（用你报名成长计划的微信号）
2. 点进你的环境（名字形如 `sofh-d0gldtpq594bcf60e`，就是你 Base URL 里那段）

## 第 2 步：创建云函数

1. 左侧菜单找 **「云函数」** → 点 **「创建云函数」**
2. 函数名填：`ai-proxy`
3. 运行环境选：**Node.js 16.13** 或更高（18/20 都行）
4. 创建方式选「空白模板」/「Hello World」（名字无所谓）
5. 内存 128M、超时改 **20 秒**（默认 3 秒不够，大模型回答要几秒）
6. 创建后点进函数 → **「函数代码」** 在线编辑器：
   - 把本文件夹里的 `index.js` 内容**整个替换**进去
   - 把 `package.json` 内容也替换进去（在线编辑器里安装依赖：右键 package.json
     或终端里执行 `npm install --production`）
7. 保存（「保存并安装依赖」按钮）

## 第 3 步：配置环境变量（防白嫖的密钥）

1. 函数页面 → **「函数配置」** → 编辑
2. 环境变量添加一条：
   - 键：`PROXY_SECRET`
   - 值：`08050fdca9581ba05795fb6b`（和后端 .env 的 AI_API_KEY 相同，已对齐）
3. 保存。云函数会自动重新部署，等状态变回"部署成功"

## 第 4 步：开启 HTTP 访问服务（让后端能从公网调到它）

1. 左侧菜单 **「云函数」→「HTTP 访问服务」**（有的版本叫「云接入」）
2. 点「创建 HTTP 触发路径」，选函数 `ai-proxy`，路径填 `/ai-proxy`
3. 打开方式选**免鉴权**（我们自己做了密钥校验，云接入这一层就不再套一道）
4. 创建后你会得到一个地址，形如：
   `https://<环境ID>.service.tcloudbase.com/ai-proxy`

## 第 5 步：把地址告诉 ZCode

把这个地址发给 ZCode（或填进 `D:\1111\default\.env` 的 `AI_BASE_URL`），
后端重启后 AI 助手即切换为真·混元 hy3。

## 常见问题

- **在线编辑器找不到装依赖的地方**：CloudBase 控制台函数代码页一般有「文件」→
  「安装依赖」或底部终端输入 `npm install --production` 回车
- **调用报 502 detail=...**：把 detail 原文发给 ZCode，多半是模型名或额度问题
- **模型列表确认**：控制台「AI」→「大模型」页能看到你环境里开通了哪些模型，
  如果没有 `hy3`，看列表里混元相关的叫什么，告诉 ZCode 改配置
